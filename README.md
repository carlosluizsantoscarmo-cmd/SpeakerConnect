# SpeakerConnect

Plataforma que conecta palestrantes a empresas: catálogo público, pedidos de orçamento, propostas, mensagens e contratação com pagamento pelo Mercado Pago (comissão da plataforma e selo de palestrante verificado).

Site e app em HTML/JS puro no Cloudflare Workers, dados no Supabase. Veja **[LEIAME.md](LEIAME.md)** para colocar no ar.
